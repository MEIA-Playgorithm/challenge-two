# Documentation style

Write every README and guide in English and in plain language. These rules follow NASA's writing standards: the NASA Glenn Content Guide and the writing standards in NPR 1450.10 (NASA Correspondence Management and Communications Standards and Style), both based on the U.S. Federal Plain Language Guidelines.

## Rules

1. **Lead with the main point.** Start each document and section with what the reader needs or can do. Put background after it.
2. **Write for one reader.** Address the reader as "you" and the team as "we".
3. **Use the active voice.** Write "We removed repeated rows", not "Repeated rows were removed".
4. **Keep sentences short.** Aim for 20 words or fewer. Put one idea in each sentence.
5. **Use short, common words.** Write "use", not "utilize"; "to", not "in order to"; "help", not "facilitate"; "start", not "commence".
6. **Avoid jargon and figures of speech.** Say exactly what you mean.
7. **Define terms and acronyms on first use.** For example: "NBA (National Basketball Association)". Explain technical terms the reader may not know.
8. **Do not use Latin abbreviations.** Write "for example", not "e.g."; "that is", not "i.e."; "and so on", not "etc.".
9. **Do not use contractions.** Write "do not", not "don't".
10. **State things positively.** Write "Keep the first copy", not "Do not keep any copy except the first". Avoid double negatives.
11. **Do not open sentences with "There is" or "It is".** Start with the subject that does the action.
12. **Use headings, lists and tables.** Make headings say what the section is for ("Get the data", not "Data acquisition"). Use lists for steps and tables for comparisons.
13. **Use links with meaningful text.** Write "Read the [data guide](docs/DATA_GUIDE.md)", not "click here".
14. **Write numbers clearly.** Use numerals for measurements and counts ("9 GB", "19 parts"), separate thousands with commas ("1,347,766") and write ranges with "to" ("2003 to 2022").

## Before you finish

Read the text aloud. If a sentence is hard to say or needs a second read, rewrite it.
